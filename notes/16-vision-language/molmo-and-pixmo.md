# Molmo and PixMo

Molmo, short for **Multimodal Open Language Model**, is a family of
vision-language models introduced together with the PixMo datasets. The work
is notable not only for model quality but for releasing model weights, training
data, source code, and evaluation resources.

This distinction matters because “open model” can mean several different
things:

- an API may be publicly accessible while weights remain private;
- weights may be downloadable while training data remains private;
- code may be visible without enough data or detail to reproduce training;
- weights, data, code, and evaluation may all be available.

Molmo aims for the last, broader form of openness.

## High-level model idea

Molmo follows the general visual-language-model pattern:

```text
image -> vision encoder -> visual tokens -> connector -> language model
text  -> tokenizer -------------------------------> language model
```

The connector maps visual features into the representation width expected by
the language model. The autoregressive language model can then generate text
conditioned on both the visual tokens and preceding text tokens.

The key lecture lesson is not a particular layer configuration. It is that
careful modeling plus carefully collected supervision can produce a strong
vision-language model without relying on captions generated by a proprietary
vision-language teacher.

## What PixMo contributes

PixMo, short for **Pixels for Molmo**, is a collection of complementary
datasets rather than one uniform caption file. Important components include:

- detailed image descriptions collected from people speaking about images;
- visual question–answer examples;
- pointing annotations for grounding, counting, and visual explanations;
- document, chart, table, clock, and counting data for targeted capabilities.

The dense-caption collection used 712,000 distinct images and 1.3 million
transcripts and captions. Its captions average far more words than ordinary
short image-caption datasets. The purpose is to describe objects, counts,
positions, text, background details, style, and other information that a short
web caption frequently omits.

## Pointing as grounded output

Molmo can produce coordinates that refer to locations in an image. Pointing
can support several behaviors:

- identify the object named in a question;
- point to every instance before reporting a count;
- connect part of a textual explanation to visual evidence;
- explicitly report that a requested object is absent.

This is richer than producing an ungrounded text answer because the output
also states where the relevant visual evidence is located.

## Relation to distillation

Many open-weight vision-language models use synthetic descriptions or answers
produced by a stronger proprietary model. This is a practical form of
[knowledge distillation](knowledge-distillation.md): the student learns from
the teacher’s behavior. It can produce capable models, but their data and
knowledge inherit a dependency on the closed teacher.

Molmo’s central data claim is different: PixMo was collected without using
external vision-language models to generate its vision-language supervision.
Language-only models and specialized tools are still used in some data
pipelines, but the visual knowledge is not simply copied from a proprietary
VLM.

## Main intuition

> Molmo and PixMo demonstrate that openness and deliberate, information-rich
> data collection are part of model design—not merely documentation choices
> made after training.
